# AWS EBS Volume Configuration

This repository/module manages an Amazon Elastic Block Store (EBS) volume configuration for the data center infrastructure.

## Volume Specifications

| Parameter | Value |
| :--- | :--- |
| **Volume Name** | `datacenter-volume` |
| **Volume Type** | `gp3` (General Purpose SSD) |
| **Volume Size** | `2 GiB` |
